# Copal skills for AI coding assistants

These skills teach your assistant to work with a team's `.copalrules`: agree the task first, follow the rules while coding, review changes, and tune noisy rules.

| Skill | When |
|---|---|
| `skills/copal-brief` | Before a feature-sized task: write `.copal/brief.md` with the developer |
| `skills/copal-check` | While coding and before each commit |
| `skills/copal-review` | Reviewing a pull request or branch |
| `skills/copal-tune` | When a rule is noisy |

Read the matching `SKILL.md` before acting. Questions where judgment matters, answers where it doesn't: fix mechanical issues, ask the developer about team decisions.
