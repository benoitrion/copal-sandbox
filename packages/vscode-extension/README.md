# Copal — your technical mentor, inside your IDE

Copal reviews your code as you write it — with or without AI. It points out what matters, asks the question a
senior developer would ask, and explains your team's standards when you want to know why.

- **Hints as you code** from your team's `.copalrules`: question first, then *Explain*, *Show me* only on request.
- **Copal: Review my change** — hint cards for everything you changed vs `main`, before you open a pull request.
- **Copal: Pair on a task** — agree the examples before an AI assistant builds; nothing beyond them.
- **Practice** — a short kata when a hint keeps coming back; mark it done from the explanation.

Works locally with no account. Set `copal.serverUrl` and a device key (*Copal: Set API key*) to see your progress in
the Copal app. Docs: https://github.com/benoitrion/copal-sandbox
